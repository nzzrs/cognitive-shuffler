# Cognitive Shuffler

A quiet, offline Android app for falling asleep with cognitive shuffling.

The app speaks a slow stream of concrete, everyday nouns — one small scene at a
time — while an optional procedural pink/brown noise bed plays underneath.
There is no account, no feed, no streak and no network permission in release
builds.

## Features

- **Cognitive shuffle cues** in English and Spanish, independently selectable
  from the interface language.
- **Phone text-to-speech**, using the voice installed on the device. No large
  model or proprietary engine is bundled.
- **Procedural noise** generated on the phone: pink ↔ brown balance, volume and
  a single warmth macro (low-pass + low-end lift).
- **Screen-off playback** through an Android foreground media service, with a
  media notification and Bluetooth/headset play/pause.
- **Sleep timer** (15–90 minutes, or until stopped), 60-second fade out by
  default, live **+15 min** action from the notification.
- **Material 3 Expressive** interface: dynamic wallpaper colour when available,
  expressive springy shapes, a true-dark night canvas.
- **No network permission** in release builds, no analytics, no ads.

## Build

Requirements:

- Flutter **3.38.8** (Dart 3.10) — pinned in `.tool-versions`
- JDK 17
- Android SDK platform 36 and build-tools 36

```sh
flutter pub get
flutter test
flutter build apk --release
```

The signed-for-testing release APK is written to
`build/app/outputs/flutter-apk/app-release.apk`. It uses the template's debug
signing key so it can be installed directly; F-Droid rebuilds and signs the app
with its own key.

### Offline builds

Flutter's release engine artifacts normally come from
`storage.googleapis.com/download.flutter.io`. On a machine where that host is
unreachable, mirror the Maven layout locally and point Flutter at it:

```sh
FLUTTER_STORAGE_BASE_URL=file:///path/to/local/mirror flutter build apk --release
```

The mirror must contain the `io.flutter:flutter_embedding_release` and
`io.flutter:<abi>_release` artifacts for the pinned engine version.

## Word data

There are no hand-written cue words in the Dart or Kotlin code. The pools are
generated by `tool/worddata/`:

```sh
python3 -m pip install -r tool/worddata/requirements.txt
python3 tool/worddata/fetch_sources.py
python3 tool/worddata/build_db.py
python3 tool/worddata/build_words.py
```

The current assets contain **558 English** and **368 Spanish** words. They are
selected from WordNet's concrete noun concepts, filtered by frequency,
concreteness ratings, dominant part of speech and a reviewed denylist. The
pipeline is deterministic; `assets/words/*.json` are committed so normal builds
and F-Droid builds never need network access.

See `tool/worddata/README.md` and `LICENSES.md` for the sources and terms.

## Known limitations

- The voice depends on the installed Android speech engine. A good offline
  engine makes a large difference; the voice can be changed in Android settings.
  Spanish requires an engine that ships a Spanish voice. GrapheneOS Speech
  Services is English-only at the time of writing, so a Spanish-capable TTS
  engine must be installed and selected in Android settings.
- The cue plan covers up to 12 hours. After the pool is exhausted, words repeat
  in a fresh shuffled order with long spacing.
- Apps cannot physically turn off the display. Playback simply continues when
  the user presses the power button; the media notification remains available.
- OEM battery managers may still stop background audio. The app uses a
  foreground service and a partial wake lock, but some vendors require an
  explicit battery-optimisation exception.
- Release builds are signed with the Flutter template debug key for local
  testing. F-Droid uses its own signing key.
